📱 Descrizione

App web progressiva (PWA) per la gestione del tuo programma di allenamento personalizzato in palestra. Consente di visualizzare esercizi, aggiungere foto delle macchine, modificare parametri di allenamento e tenere traccia dei progressi.

✨ Caratteristiche Principali

✅ 3 Programmi di Allenamento - Giorni A, B e C con esercizi specifici

✅ Visualizzazione Dettagliata - Ripetizioni, carico e recupero per ogni serie

✅ Foto Personalizzate - Scatta o carica foto delle macchine/esercizi

✅ Modalità Modifica - Personalizza nomi esercizi e parametri

✅ Navigazione Intuitiva - Swipe, frecce e pulsanti di navigazione

✅ Salvataggio Automatico - Tutte le modifiche e foto salvate localmente

✅ Installabile - Funziona come app nativa su smartphone

📱 Installazione

iPhone/iPad

  1. Apri l'app in Safari
    • Assicurati di usare Safari (non Chrome o altri browser)
    • Vai a: https://bob0b0.github.io/allenamento
  2. Aggiungi alla Home Screen
    • Tocca il pulsante "Condividi" (quadrato con freccia verso l'alto)
    • Scorri e tocca "Aggiungi a Home"
    • Conferma toccando "Aggiungi"
  3. Avvia l'app
    • L'icona apparirà sulla Home Screen
    • Tocca per aprire l'app in modalità standalone

Android

  1. Apri l'app in Chrome
    • Usa Chrome come browser
    • Vai a: https://bob0b0.github.io/allenamento
  2. Installa l'app
    • Tocca i tre puntini in alto a destra
    • Seleziona "Aggiungi a schermata Home" o "Installa app"
    • Conferma l'installazione
  3. Avvia l'app
    • L'icona apparirà sulla Home Screen
    • Tocca per aprire l'app

🏋️ Utilizzo dell'App

Schermata Iniziale

Dalla home screen, scegli il tuo programma di allenamento:

  • Giorno A - 9 esercizi
  • Giorno B - 10 esercizi
  • Giorno C - 9 esercizi

Visualizzazione Esercizio

Ogni esercizio mostra:

Header

  • Badge colorato del tipo (Macchina, Pesi Liberi, Cavi, Corpo Libero, Cardio)
  • Nome dell'esercizio
  • Nome della macchina (se applicabile)

Foto

  • Area bianca con placeholder o foto personalizzata
  • Icona fotocamera in alto a destra per scattare/caricare foto

Tabella Allenamento

RIP KG REC.
10 25,5 180″
9 30 180″
9 30 180″
  • RIP = Ripetizioni da eseguire
  • KG = Carico in chilogrammi
  • REC. = Recupero in secondi

Note Tecniche

Riquadro giallo con consigli sull'esecuzione corretta

📷 Aggiungere/Modificare Foto

  1. Tocca l'icona fotocamera (📷) sull'immagine dell'esercizio
  2. Scegli:
    • Scatta foto - Usa la fotocamera
    • Scegli dalla libreria - Seleziona foto esistente
  3. La foto viene automaticamente compressa (max 800×600px, qualità 75%)
  4. La foto compressa viene salvata in localStorage

Nota: La compressione automatica permette di salvare tutte le 28 foto (9+10+9 esercizi) mantenendo una qualità sufficiente per riconoscere le macchine.

✏️ Modificare Parametri

  1. Tocca i tre puntini (⋯) accanto al nome della macchina
  2. Entra in modalità modifica:
    • Il nome dell'esercizio diventa modificabile
    • I valori nella tabella (RIP, KG, REC.) diventano modificabili
  3. Modifica i valori desiderati
  4. Tocca 💾 Salva per confermare le modifiche

Nota: Se cambi esercizio mentre sei in modalità modifica, le modifiche vengono salvate automaticamente.

🔄 Navigazione tra Esercizi

Metodo 1: Swipe

  • Swipe verso sinistra → Esercizio successivo
  • Swipe verso destra → Esercizio precedente

Metodo 2: Pulsanti

  • Tocca ◀ Prec → Esercizio precedente
  • Tocca Succ ▶ → Esercizio successivo

Metodo 3: Dots

  • Tocca uno dei pallini in basso per saltare a un esercizio specifico
  • Il pallino azzurro allungato indica l'esercizio corrente

Tornare alla Home

  • Tocca l'icona casa (🏠) in alto a sinistra

💾 Gestione Dati

Dove Vengono Salvati i Dati

Tutti i dati sono salvati localmente sul tuo dispositivo tramite localStorage:

  • ✅ Foto degli esercizi
  • ✅ Modifiche ai nomi degli esercizi
  • ✅ Modifiche ai parametri (ripetizioni, carico, recupero)

Backup e Restore

Accesso alla funzione:

  1. Dalla schermata principale (home), sotto i pulsanti dei giorni A/B/C
  2. Tocca il link "Import/Export Dati"
  3. Si aprirà una finestra con le opzioni

Esportare i Dati (Backup):

  1. Tocca il pulsante 📥 Export
  2. Su iPhone: Si aprirà un'anteprima del file
    • Tocca "Altro..." in basso
    • Seleziona "Salva su File"
    • Scegli la cartella "Download" o "iCloud Drive"
    • Tocca "Salva"
  3. Su Android: Il file viene scaricato automaticamente nella cartella Download
  4. Nome file: allenamento_backup_AAAA-MM-GG.json
  5. Conserva questo file in un luogo sicuro (cloud, computer, ecc.)

Importare i Dati (Restore):

  1. Tocca il pulsante 📤 Import
  2. Seleziona il file di backup precedentemente salvato
  3. I dati verranno ripristinati automaticamente
  4. L'app si aggiornerà con foto e modifiche del backup

Quando fare un backup:

  • ✅ Prima di cambiare smartphone
  • ✅ Periodicamente per sicurezza
  • ✅ Prima di cancellare i dati del browser
  • ✅ Se vuoi condividere il tuo programma con qualcuno

Persistenza dei Dati

  • I dati rimangono anche se chiudi l'app
  • I dati rimangono anche se riavvii il dispositivo
  • I dati sono specifici per ogni esercizio (identificati tramite ID univoco)

Cancellare i Dati

Per resettare l'app e cancellare tutte le modifiche:

iPhone/iPad:

  1. Apri Impostazioni → Safari → Avanzate
  2. Dati dei siti web → Rimuovi dati del sito specifico

Android:

  1. Impostazioni → App → Chrome (o il tuo browser)
  2. Archiviazione → Cancella dati

🐛 Risoluzione Problemi

L'app non si installa

  • Verifica di usare il browser corretto (Safari su iOS, Chrome su Android)
  • Prova a ricaricare la pagina

Le foto non vengono salvate

  • Verifica i permessi della fotocamera/galleria nelle impostazioni del dispositivo
  • Assicurati di non essere in modalità navigazione privata
  • Le foto vengono automaticamente compresse per risparmiare spazio (qualità sufficiente per riconoscere le macchine)
  • Se hai già molte foto salvate, prova a eliminarne alcune per liberare spazio

Le modifiche non vengono salvate

  • Tocca sempre "💾 Salva" prima di uscire dalla modalità modifica
  • Verifica che il browser abbia i permessi di archiviazione

L'app è lenta

  • Chiudi altre app in background
  • Le foto molto grandi possono rallentare l'app (considera di ridimensionarle)

Problemi con Import/Export

  • iPhone: Dopo Export, ricorda di toccare "Altro..." → "Salva su File" per salvare il backup
  • Assicurati che il file di backup sia in formato .json
  • Non modificare manualmente il file di backup
  • Se l'import fallisce, verifica che il file non sia corrotto
  • Per cambiare dispositivo: Export sul vecchio → Trasferisci file → Import sul nuovo

📝 Note per l'Uso in Palestra

Consigli Pratici:

  • 📸 Scatta foto delle macchine al primo utilizzo per identificarle facilmente
  • 🖼️ Le foto vengono compresse automaticamente a 800×600px - la qualità è sufficiente per riconoscere le macchine
  • 💾 Puoi caricare fino a 28 foto totali (tutte le macchine dei 3 giorni)
  • ✏️ Aggiorna i pesi dopo ogni allenamento per tracciare i progressi
  • 🔢 Usa il formato "180″" per i secondi di recupero (es. 3 minuti = 180″)
  • 📱 Tieni lo schermo attivo durante l'allenamento nelle impostazioni del telefono

Formato Dati:

  • Ripetizioni: Numero intero (es. 10, 12, 15)
  • Carico: Numero con virgola o punto (es. 25,5 o 25.5)
  • Recupero: Secondi con doppi apici (es. 60″, 120″, 180″)
